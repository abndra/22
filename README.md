# سيرفر إشعارات واتساب (Railway)

سيرفر بسيط يرسل إشعار كل طلب جديد إلى رقم الواتساب المحدَّد في لوحة التحكم.

## خطوات النشر

1. أنشئ مستودع (Repository) جديد على GitHub وارفع فيه ملفات هذا المجلد.
2. ادخل على https://railway.app › New Project › Deploy from GitHub repo واختر المستودع.
3. من تبويب **Variables** أضف:
   - `SERVICE_TOKEN` = توكن سري تختاره أنت (نفسه ستضعه في لوحة التحكم).
   - `AUTH_DIR` = `/data/auth`
4. من تبويب **Settings** › Volumes أضف Volume واجعل **Mount Path = /data**. هذه الخطوة إلزامية؛ بدونها تُحذف الجلسة عند إعادة التشغيل أو النشر.
5. من **Settings › Networking** اضغط Generate Domain لتحصل على رابط مثل:
   `https://xxxx.up.railway.app`
6. في لوحة تحكم المتجر › الإعدادات › سيرفرات واتساب: أضف اسم السيرفر + الرابط + التوكن ثم **حفظ السيرفر** و**تفعيل**.
7. اضغط **اختبار** وسيظهر رمز QR — امسحه من واتساب › الأجهزة المرتبطة › ربط جهاز.

بعدها كل طلب جديد يصل مباشرة كرسالة واتساب على الرقم المحدد. عند تعطّل السيرفر يبقى الطلب محفوظاً ولا يُفتح واتساب عند الزبون.

زر **إعادة تهيئة** يعيد الاتصال مع الاحتفاظ بالجلسة. زر **تسجيل خروج وإظهار QR** يحذف الجلسة عمداً ويولّد رمزاً جديداً.

## نقاط النهاية
- `GET /status` — حالة الاتصال + رمز QR (يتطلب Authorization: Bearer TOKEN)
- `POST /send` — `{ "to": "96894913233", "message": "..." }`
- `POST /restart` — إعادة تهيئة الاتصال مع الاحتفاظ بالجلسة
- `POST /logout` — تسجيل خروج وحذف الجلسة وتوليد QR جديد
